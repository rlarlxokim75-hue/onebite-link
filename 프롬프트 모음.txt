링크 추가 기능을 구현해
- 사용자가 새 링크를 추가하면, links 테이블에 보관해
- 새 링크페이지의 추가(저장)버튼의 중복 클릭을 막아서, 여러개의 링크가 동시에 추가되지 않도록 해줘
- 새링크 페이지에 폴더를 선택하는 셀렉트 박스에 현재 folders 테이블에 보관된 모든 폴더의 목록을 나열해
- 추가된 링크들을 인덱스 페이지나 폴더별 페이지에 불러와서 보여주는 기능도 추가해
- 이 외에 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해




링크 수정 기능을 구현해
- 링크 수정시 변경된 정보들을 links 테이블에 업데이트 해줘
- 이 외에 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해

링크 삭제기능을 구현해
- 링크 삭제시 links 테이블에서 해당 데이터를 제거해줘
- 이 외에 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해




링크 테이블을 생성해줘
- 컬럼 : id, url, title, description, thumbnail_url, created-at
- id 컬럼에 오토 인크리먼트, 프라이머리 키 설정
- id, url, created_at 컬럼은 필수 컬럼으로 설정, 나머지는 선택적 컬럼으로 설정해 
- RLS는 꺼줘



폴더 테이블을 생성해줘
- 컬럼 : id, name, created_at
- id 컬럼에 오토 인크리먼트, 프라이머리키를 설정해
- 모든 컬럼을 필수 컬럼으로 설정
- RLS 를 꺼줘



링크 테이블과 폴더 테이블을 연결해줘
- 링크 테이블에 folder-id 라는 컬럼을 추가해줘
- folder_id 컬럼은 선택적 컬럼으로 설정해줘
- folder_id 컬럼이 folder 테이블의 id 컬럼을 참조하도록 외래키로 설정해줘
- folder 테이블의 데이터가 삭제될 경우(폴더 삭제) 연결된 link 테이블의 folder_id 를 빈 값으로 설정해줘



폴더 추가 기능을 구현해
- 사용자가 추가한 폴더를 folders 테이블에 추가해
- 폴더 추가 버튼의 중복 클릭을 막아서, 여러개의 폴더가 동시에 추가되지 않도록 해줘
- 좌측 사이드바에 folders 테이블에 보관된 폴더들을 불러와서 순서대로 나열해줘
- 이 외에 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해


폴더 이름을 수정하는 기능을 구현해
- 폴더 이름 수정시 folders 테이블에 수정된 이름이 업데이트 되도록 해줘
- 이 외에 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해


폴더 삭제 기능을 구현해
- 사용자가 폴더를 삭제했을 때 folders 테이블에서 해당 폴더를 제거해
- 이 외에 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해
